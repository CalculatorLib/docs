## Configure

Open **Windsurf Settings → Cascade → MCP Servers → Add Server** (or edit `~/.codeium/windsurf/mcp_config.json` directly) and add:

```json mcp_config.json
{
  "mcpServers": {
    "calculatorlib": {
      "serverUrl": "https://calculatorlib.com/mcp"
    }
  }
}
```

<Note>
Windsurf uses the key `serverUrl` (not `url`) for remote servers.
</Note>

Press the refresh button in the MCP panel after saving.

## Verify

`calculatorlib` should appear in Cascade's MCP server list with its tools. Then ask Cascade:

```
What's 250 kWh in megajoules?
```

It should call `convert_energy` and return `900 MJ`.
