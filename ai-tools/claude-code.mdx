## One-line install

From any terminal:

```bash
claude mcp add --transport http calculatorlib https://calculatorlib.com/mcp
```

That's it — the server is remote, so there is nothing to download or run locally.

## Or configure via `.mcp.json`

To share the server with everyone working in a repository, add it to a `.mcp.json` file at the project root:

```json .mcp.json
{
  "mcpServers": {
    "calculatorlib": {
      "type": "http",
      "url": "https://calculatorlib.com/mcp"
    }
  }
}
```

## With an API token (optional)

To use your [`clk_` token](/authentication) for the 600 req/min limit:

```bash
claude mcp add --transport http calculatorlib https://calculatorlib.com/mcp \
  --header "Authorization: Bearer clk_YOUR_TOKEN_HERE"
```

## Verify

Run `/mcp` inside a Claude Code session — `calculatorlib` should be listed as connected with the `search_calculators`, `get_calculator_schema`, `run_calculator`, and `convert_*` tools.

Then try:

```
What's the monthly payment on a $420,000 mortgage at 6.5% over 30 years?
```

Claude will search the library, run the mortgage calculator, and answer with the worked formula and a link to the result page.
