## Configure

Open **Cursor Settings → MCP → Add new MCP server**, or edit the config file directly:

- **Global**: `~/.cursor/mcp.json`
- **Per-project**: `.cursor/mcp.json` in the project root

```json mcp.json
{
  "mcpServers": {
    "calculatorlib": {
      "url": "https://calculatorlib.com/mcp"
    }
  }
}
```

Cursor detects the URL as a Streamable HTTP server automatically — no local process needed.

## With an API token (optional)

To use your [`clk_` token](/authentication) for the higher rate limit:

```json mcp.json
{
  "mcpServers": {
    "calculatorlib": {
      "url": "https://calculatorlib.com/mcp",
      "headers": {
        "Authorization": "Bearer clk_YOUR_TOKEN_HERE"
      }
    }
  }
}
```

## Verify

In the MCP settings panel, `calculatorlib` should show a green status with its tools listed. Then ask the agent:

```
Convert 90 mmHg to kPa
```

It should call `convert_pressure` and return `11.999… kPa`.
