Turn a calculator into a spreadsheet formula: put your inputs in cells, get results in others. Inputs are passed as **alternating `key, value` arguments**, and either side can be a literal or a cell reference. Both add-ons work without a token (subject to the [anonymous per-minute limits](/rate-limits)); add your `clk_` [API token](https://calculatorlib.com/account/api-tokens) to lift those limits and draw on your account's monthly quota.

## Google Sheets

Three custom functions, added through Apps Script:

| Function | Returns |
|---|---|
| `=CALCLIB(slug, key, value, …)` | The **first** result field's value (a number when it can be coerced to one). |
| `=CALCLIB_FIELD(slug, field, key, value, …)` | One result field, by key. |
| `=CALCLIB_ALL(slug, key, value, …)` | Every result field — a 2-column spill of `[label, value]` rows. |

Inputs come after the slug (or, for `_FIELD`, after the field name) as alternating **key, value** pairs. Values can be literals or cell references — e.g. `"height", A2, "weight", B2`. Store your token once in a **Script Property** named `CALCLIB_TOKEN`.

```text Example
=CALCLIB("bmi-calculator", "height", 175, "weight", 70)
```

```text With cell references
=CALCLIB("bmi-calculator", "height", A2, "weight", B2)
```

## Excel

An Office.js add-in adds two custom functions (there's no `_ALL` in Excel):

| Function | Returns |
|---|---|
| `=CALCLIB.RUN(slug, key, value, …)` | The **first** result field's value (a number when it can be coerced to one). |
| `=CALCLIB.FIELD(slug, field, key, value, …)` | One result field, by key. |

Same alternating **key, value** arguments (literals or cell references). Set your token in the add-in's task pane — it's kept in the browser's `localStorage`.

```text Example
=CALCLIB.RUN("bmi-calculator", "height", 175, "weight", 70)
```

<Note>
Use the calculator's **exact field names** as the keys — get them from [`GET /api/calculator/ui/{slug}`](/api-reference/introduction). Unknown keys fall back to defaults ([why](/guides/errors-and-caveats)). Without a token you get the anonymous per-minute limits; when a formula returns `429`, the message tells you to add a token.
</Note>
