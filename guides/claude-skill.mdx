The CalculatorLib **Skill** (a `SKILL.md` package) teaches Claude to search the library and run calculators for you. It's **MCP-first**: it uses the [CalculatorLib MCP server](/mcp/overview) when the client has it configured, and falls back to the public [REST API](/api-reference/introduction) otherwise — so it works with or without MCP.

Because every calculation runs on CalculatorLib's own engine, the results match the website exactly — Claude never does the arithmetic itself.
