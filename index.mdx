## What is CalculatorLib?

[CalculatorLib](https://calculatorlib.com) hosts thousands of calculators — finance, health, math, statistics, geometry, date & time, science, cooking, fitness — plus a large unit-conversion engine covering 60+ measurement categories. Every calculator that runs on the website can also be run programmatically:

- **REST API** — plain JSON over HTTPS. Search calculators, read their input schemas, execute them, and convert units.
- **MCP server** — a [Model Context Protocol](https://modelcontextprotocol.io) endpoint at `https://calculatorlib.com/mcp` that gives Claude, Cursor, and any MCP client direct access to the whole library.

Both are **free and public**. No signup is required to start; an optional API token raises your MCP rate limit 10×.

## The two surfaces at a glance

| | REST API | MCP server |
|---|---|---|
| Base URL | `https://calculatorlib.com/api/...` | `https://calculatorlib.com/mcp` |
| Protocol | JSON over HTTPS | JSON-RPC 2.0 (Streamable HTTP) |
| Best for | Backends, scripts, integrations | AI agents and chat clients |
| Auth | None (public) | Optional `clk_` token → higher limits |
| Discover calculators | `GET /api/calculators/search` | `search_calculators` tool |
| Read input schema | `GET /api/calculator/ui/:slug` | `get_calculator_schema` tool |
| Execute a calculator | `POST /api/calculator/execute/:slug` | `run_calculator` tool |
| Convert units | `POST /api/converter/convert` | `convert_<category>` tools |

<Warning>
`POST /api/calculator/execute/:slug` silently falls back to **default values** for any input name it doesn't recognize — it does not return an error for a misspelled field. Always fetch the exact input names from `GET /api/calculator/ui/:slug` first. See [Errors & caveats](/guides/errors-and-caveats).
</Warning>

## For LLMs and AI assistants

CalculatorLib publishes an [`llms.txt`](https://calculatorlib.com/llms.txt) at the site root, following the [llmstxt.org](https://llmstxt.org) convention, so AI assistants can discover the calculator library and its API on their own.
