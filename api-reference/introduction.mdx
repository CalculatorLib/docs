## Base URL

```
https://calculatorlib.com
```

All endpoints are served over HTTPS and return JSON. The REST API requires **no authentication** — see [Authentication](/authentication) for the one place tokens matter (the MCP endpoint).

## Endpoint map

| Endpoint | Purpose |
|---|---|
| `GET /api/calculators/search` | Find calculators by keyword |
| `GET /api/calculators/schemas` | Search with agent-ready input schemas (MCP catalog) |
| `GET /api/calculator/ui/{slug}` | A calculator's form schema + result fields |
| `POST /api/calculator/execute/{slug}` | Execute a calculator with your inputs |
| `GET /api/converter/categories` | All converter categories and their unit enums |
| `POST /api/converter/convert` | Convert a value between units |
| `GET /api/converter/paths` | Every converter page URL path |
| `GET /api/mcp/stats/{slug}` | Per-calculator usage stats |
| `GET /api/stats/total` | Site-wide live calculation counter |
| `POST /mcp` | The MCP server (JSON-RPC 2.0) |

## The intended flow

```text
search (find the slug)  →  ui (get exact field names)  →  execute (compute)
```

<Warning>
Never skip the `ui` step: `execute` silently substitutes **default values** for unknown or missing input names instead of erroring. Details in [Errors & caveats](/guides/errors-and-caveats).
</Warning>

## Conventions

- Calculator endpoints wrap success as `{"status": "ok", "data": {...}}` and errors as `{"error": {...}}`.
- `resultFields[].value` is the raw value (as a string); `display` is the human-formatted version.
- Slugs use hyphens (`bmi-calculator`); MCP tool names use underscores (`bmi_calculator`).
- Search is rate limited at 60 req/min per IP; other REST endpoints rely on edge-level protection. See [Rate limits](/rate-limits).

Each endpoint page in this section is generated from the [OpenAPI specification](https://github.com/calculatorlib/docs/blob/main/api-reference/openapi.json) and includes an interactive playground.
