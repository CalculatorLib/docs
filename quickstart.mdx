Everything below works with no API key. The base URL for all requests is `https://calculatorlib.com`.

<Steps>
<Step title="Search for a calculator">

Find a calculator by keyword. Each result includes the `slug` you'll use in the next two steps.

```bash
curl "https://calculatorlib.com/api/calculators/search?q=bmi&limit=3"
```

```json Response (trimmed)
{
  "status": "ok",
  "data": {
    "results": [
      {
        "slug": "bmi-calculator",
        "name": "BMI Calculator",
        "h1": "BMI Calculator",
        "category_name": "General"
      }
    ],
    "query": "bmi",
    "total": 1,
    "has_more": true,
    "language": "en"
  }
}
```

</Step>
<Step title="Read the calculator's input schema">

**Do not skip this step.** The execute endpoint identifies inputs by their exact field names — get them from the UI schema:

```bash
curl "https://calculatorlib.com/api/calculator/ui/bmi-calculator"
```

```json Response (trimmed)
{
  "status": "ok",
  "data": {
    "slug": "bmi-calculator",
    "h1": "BMI Calculator",
    "form": [
      {
        "field": "unitSystem",
        "field_type": "select",
        "default_value": "metric",
        "text": "Unit System:",
        "options": [
          { "label": "Metric (kg, cm)", "value": "metric", "selected": true },
          { "label": "Imperial (lbs, ft/in)", "value": "imperial", "selected": false }
        ]
      },
      { "field": "weight", "type": "number", "text": "Weight (kg):", "default_value": "70" },
      { "field": "height", "type": "number", "text": "Height (cm):", "default_value": "175" },
      { "field": "weightLbs", "type": "number", "text": "Weight (lbs):", "is_hidden": true },
      { "field": "heightFt", "type": "number", "text": "Height (feet):", "is_hidden": true },
      { "field": "heightIn", "type": "number", "text": "Height (inches):", "is_hidden": true }
    ],
    "resultFields": [
      { "key": "bmi", "value": "22.857", "display": "22.9", "label": "Your BMI", "type": "number" }
    ],
    "triggerFields": ["unitSystem"]
  }
}
```

The `form` array tells you each input's `field` name, its type, its default, and (for selects) the allowed values. `is_hidden: true` fields belong to an alternate mode — here, the imperial inputs that appear when `unitSystem` is `"imperial"`.

</Step>
<Step title="Execute the calculator">

POST the inputs using the **exact `field` names** from step 2:

```bash
curl -X POST "https://calculatorlib.com/api/calculator/execute/bmi-calculator" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"unitSystem": "metric", "weight": 70, "height": 170}}'
```

```json Response
{
  "status": "ok",
  "data": {
    "slug": "bmi-calculator",
    "resultFields": [
      {
        "key": "bmi",
        "value": "24.221453287197235",
        "display": "24.2",
        "label": "Your BMI",
        "type": "number"
      }
    ]
  }
}
```

`value` is the raw numeric result; `display` is the human-formatted version shown on the website.

</Step>
</Steps>

<Warning>
**Wrong input names fail silently.** If you send `{"inputs": {"Weight": 70}}` (wrong case) or `{"inputs": {"mass": 70}}` (wrong name), the API does **not** return an error — it computes the result using the calculator's default values instead. If your results look like they ignore your inputs, re-check the field names against `GET /api/calculator/ui/:slug`.
</Warning>

## Bonus: convert a unit

```bash
curl -X POST "https://calculatorlib.com/api/converter/convert" \
  -H "Content-Type: application/json" \
  -d '{"category": "Length", "value": 5, "from": "Meter", "to": "Foot"}'
```

```json Response
{
  "category": "length",
  "from": "Meter",
  "to": "Foot",
  "value": 5,
  "result": 16.404199475065617
}
```

Unit names are case-sensitive; list them all with `GET /api/converter/categories`.
